# Checker 패턴·거래 레시피 — 술어의 표준형 여섯 (v0.2 · 2026-08-25 · [M-125] 레시피 5종+발견층 관례)

**지위**: 관례 문서(커널·노드 무접촉 — 코드가 아니라 **쓰는 법**이다). 모든 패턴은
수용 게이트의 술어-공간 안에서 실증됐다(정족수·표본·샤딩·리플레이 — 개발 저장소의
실측 하네스 5회전·결정론 지문 동일 · 게이트 스위트 `test_r1.py`가 같은 기전을 상시
검증). 정본 = 한국어. 근거 연구 = 개발 저장소(비공개)의 PILLARS_CREATIVE_RESEARCH —
요지는 본 문서가 자기완결로 담는다.

**공통 원리**: 커널은 스펙을 해석하지 않고 통째로 서명-결박한다(스펙-불투명) ⟹ 아래
패턴 전부가 **커널 동결과 무관하게** 성립한다. checker의 수용 = 마지막 비-공백 줄이
정확히 `OK`. 상한: 실행 10초 · 파일 64KB · 무-네트워크 · 무-PATH.

## P-1 정족수-판정 (quorum) — 비결정론 판정을 결정론으로 집계

**마커 규약**: 판정-잡(judge-job)의 산출 프로그램은 ⓐ첫 줄 주석 `# VERDICT: PASS`
(또는 `FAIL`) ⓑstdout 첫 줄에 같은 판정을 출력한다. 형식 checker:

```python
v = open('output.txt').read().splitlines()
assert v and v[0] in ('PASS', 'FAIL')
print('OK')
```

**집계-잡**: k건의 판정을 모아 다수결 자체를 정산한다 — input에 각 판정의
`output_b64`(원문)와 `output_sha256`(원장의 DELIVER에 결박된 값)을 넣고, checker가
①해시-결박 검사 ②마커 파스 ③다수결을 판정한다(전문 = creative_demos의 `AGG`).

**무엇이 보증되나**: 집계가 참조한 판정-바이트가 위조면 정산이 거부되고(실증),
외부 감사자는 **로그-단독으로** 「어떤 판정들이 이 정족수에 들어갔나」를 대조할 수
있다(input의 해시 ↔ 원장의 output_sha256). **무엇이 아닌가**: 판정 **내용**의 참은
보증되지 않는다 — 오판은 검증이 아니라 인수의 몫([M-120]).
★실측 주의: 정족수는 크기보다 **패널 구성**이 지배한다(눈먼 판정자 2를 섞은 k=5가
좋은 판정자 k=3보다 낮았다 — 두 시드 재현). 판정자 선택의 원료 = 이탈-지표(R2).

## P-2 시드-몬테카를로 (seeded-MC) — 통계적 수용도 결정론이다

성질-검사를 고정-시드 무작위 사례로 돌리면 술어는 결정론이다:

```python
import random, sys
sys.path.insert(0, '.')
exec(compile(open('output.txt','rb').read(), 'sol.py', 'exec'), globals())
for seed in range(200):                      # 시행수 n = 검증 깊이(스펙에 명시)
    rng = random.Random(seed)
    arr = [rng.randint(-10**6, 10**6) for _ in range(rng.randint(0, 60))]
    assert solve(list(arr)) == sorted(arr), f'seed {seed}'
print('OK')
```

**깊이 = 가격**: n이 클수록 탈출률이 낮다(실측 곡선: 경계-버그는 n≈200에서 0 ·
희귀-버그는 n=400에도 0.35 탈출) — n은 스펙의 일부로 공표하고, 잔여 탈출률은 보험이
가격한다([R-SAMPLE] 쌍대). 예산: 싼 시행은 10초에 ~10⁵회 수준(시행 비용에 선형).

## P-3 술어 샤딩 (shard) — 10초 예산 벽의 시장-우회

큰 n을 m개의 잡으로 나눠 각각 정산하고(시드 창 분할), 집계-잡이 m개 산출의
해시-결박을 공증한다(P-1의 집계와 동형 — 실측: 400시행 = 4×100 샤드 전량 정산).
검증 총량의 상한이 **한 checker의 예산이 아니라 시장 용량**이 된다. 비용 = m AU ·
지연 = 병렬.

## P-4 파이프라인 (deps) — 다단 작업의 단계별 정산

후속 잡의 input에 선행 잡의 `{ref, output_sha256}`와 산출 원문을 결박한다
(judge-job의 `input_b64` 관례의 일반형). 각 단계가 독립 정산되고, 전체 사슬은 H2로
로그-감사 가능 — 단계별 금융 최종성이 있는 파이프라인. ⚠️결박 검사는 checker-내
해시 대조까지이고 **원장-대조는 감사자 절차**다(자동 아님 — 정직).

## P-5 계약-조항 (clause) — 스펙-조항 + 운영자 ATTEST 집행

스펙에 조항을 넣으면 H2가 서명-head에 결박한다. 커널이 집행하지 않는 조항(예: 잡별
기한)은 **운영자 ATTEST_FAIL(reason 명시)** 로 집행된다 — 기한 조항이 첫 실증
([M-120]: `deadline:d` 초과 시 조기-성숙·부보 폭포 정상 정산). 조항 어휘는 대역-외
공표(ANCHOR_SCOPE 방식)와 함께 써라. **신뢰 고지**: 조항 집행자 = 운영자(v0 기존
신뢰 경계 안 — 새 신뢰 아님).

## P-6 공증-잡 (notarize) — 스펙-계산 가능한 사실의 원장 기입

checker가 input(스펙-결박)만으로 판정을 끝내는 잡은, 정산 자체가 「그 사실의 공증」이
된다(P-1 집계·P-3 집계가 이 형태). 표준화 시 checker가 산출-에코도 검사하게 하라
(이행이 공허해지지 않게).

## 거래 레시피 다섯 (마찰을 줄이는 표준 순서)

**R-1 낯선 상대 고용** (내가 상대 색 노트가 없을 때):
①상대가 회전-발행으로 자기-IOU 확보(`c.issue(k)` — 유통 ≤ 한도) ②원자 스왑: 내 노트
↔ 상대 노트(`make_leg` 교환 → `submit_block` — 둘 다 서명·전부-아니면-무) ③이제 상대-색
노트로 `redeem_job`(에스크로·기한·검증이 붙는다). — 신용 관계 0에서 두 엔트리.

**R-2 보험료 원자-교환**: 인수자 `cover(ref, prem, submit=False)`로 UW 다리 서명 →
홀더 XFER 다리(보험료 노트) 서명 → 한쪽이 `submit_block([uw_leg, xfer_leg])` —
커버와 보험료가 같은 엔트리에서 성립(둘 중 하나만 되는 일이 없다).

**R-3 판정 주문**: `judge_job(judge_anchor, nid, target_ref, checker_py)` — 대상 잡
산출이 input으로 결박되고 verdict가 공개 정산된다. 정족수가 필요하면 판정자 k명에게
반복 후 P-1 집계.

**R-4 자원-앵커** ([M-125] — 실물 자원[GPU-시간·스토리지·API 쿼터]의 연계 레시피):
자원 보유자가 앵커로 참여해 "1 AU = 내 자원 X"를 ASK로 공표하고, **이행의 검증 =
프로브**다 — 매수자가 정답-기지 카나리 잡(sha256 계열이 그대로 프로브)을 **무작위
시점에** 상환으로 투입한다. 프로브 무이행 = 시한-사고 = p̂ 악화 ⟹ 자원의 실재·가동률이
기록으로 가격화된다(용량 자체의 암호학적 증명이 아니라 **표본-가동률 + 기록**·잔여는
보험 — 확장 정리의 적용). 페그 없음: 자원-앵커 노트의 교환비는 테이프가 발견한다.

**R-5 교환-앵커** ([M-125] — 온체인 자산 등 원장-밖 이행의 레시피 · ⚠️제3자 몫):
이행이 원장 밖(예: 온체인 이체)인 앵커. checker는 원장-밖을 못 본다(무-네트워크) ⟹
정통 문형 = **사전 조율 + 완료-시점 상환**(ANCHOR_SCOPE의 큰-과제 문형 그대로):
합의 → 원장-밖 이행 → 매수자가 영수증(tx 등)을 **자가-검증** → 완료 시점에 상환을
걸고 즉시 이행-정산. ⚠️에스크로 보호는 **정산-창에 한정**되고 원장-밖 구간의 신용
위험은 상호 평판·판정-시장 증언·인수의 몫이다(정직 고지 필수 — 이 레시피는 신뢰가
재유입되는 자리임을 숨기지 않는다). 운영자는 이 앵커를 하지 않는다(NOTICE 불변).

## 발견층 관례 — 신규-앵커 노출 ([M-125] · 냉각 처방)

기록-기반 선택은 콜드스타트에서 고착한다(실측 — 무-기록 앵커는 선택이 안 와 영원히
무-기록: [FR-7] 냉각의 발견층 재현). 처방은 매수자-측 관례다: ⓐ**신규 판별** = 보드
게시자가 `/stats.anchors`에 세그먼트가 없으면 신규(파생-가시 — 코드 불요)
ⓑ**ε-탐험** = 선택의 일부(권장 ~10–15%)를 신규·저-이력 앵커에 배정한다(실측: ε=0.15
에서 기록-학습이 즉시 수렴 — 탐험 비용은 소액-액면으로 한정하라). 보드-측 신규 표시는
R2 선택항.

## 정직 요약 (전 패턴 공통)

보증되는 것 = **약속-일치**(스펙에 적힌 술어의 통과)와 **결박**(무엇이 걸렸고 무엇이
나왔는지의 위조-불가). 보증 안 되는 것 = 술어 밖 품질·판정 내용의 참·표본 밖 잔여 —
그 잔여는 가격(보험료·요율)의 몫이고, 그래서 이 시장의 상품은 「확실성의 등급」이다.

★**산출-크기 계약**([M-149]): 산출 stdout 은 **1MB**, 판정(checker) 출력은 **4KB**가
상한이고, **초과는 절단-심사가 아니라 명시 거부**다(사유: 「상한 초과」). checker 는
심사한 바이트열이 이행자가 만든 전량임을 전제해도 된다 — 큰 산출이 필요한 작업은
스펙에서 산출을 요약형(해시·체크포인트)으로 설계하라(P-2·P-3 참조).
